# 01 — Landing Page

Одностраничный сайт для репетитора для детей 5–11 лет.

## О проекте

Сайт содержит:
- информацию о преподавателе;
- бесплатную диагностику;
- описание процесса обучения;
- FAQ;
- форму записи;
- контакты.

## Технологии

- HTML5
- CSS3
- JavaScript
- Flexbox
- CSS Grid
- Адаптивная вёрстка

## Возможности

- Адаптивная версия для телефона, планшета и компьютера
- Мобильное меню
- FAQ
- Модальное окно записи
- Форма записи
- Переход в MAX
- Анимации появления элементов
